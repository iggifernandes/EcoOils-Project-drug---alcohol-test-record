# EcoOils Mentari — Alcohol Records

Static web app (GitHub Pages). Logs breathalyzer tests to the shared Google Sheet ("Sheet1" tab) through the Apps Script web app set in `SHEETS_WEBHOOK_URL` inside `index.html`.

Files: `index.html`, `personnel-lists.js`, `combobox.css` — keep them in the same folder.

`personnel-lists.js` and `combobox.css` are duplicated in the Blood Pressure repo. Change a master list in one place, change it in the other.
